# 📘 Teste Prático - EAD Unifor

## 🚀 Como rodar com Live Server 

1. **Pré-requisitos**  
   - [Visual Studio Code](https://code.visualstudio.com/)  
   - Extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)

2. **Clone ou baixe o projeto**
   ```bash
   git clone https://github.com/seu-usuario/tutorial-algoritmos.git
   ```

   Ou baixe o ZIP e extraia para uma pasta.

3. **Abra no VS Code e inicie o Live Server**
  - Abra a pasta do projeto no VS Code
  - Clique com o botão direito no arquivo tutorial_algoritmos.html > Open with Live Server
ou clique em "Go Live" no canto inferior direito

4. **Acesse no navegador**
   
   O Live Server abrirá automaticamente em algo como:
   
   http://127.0.0.1:5500/tutorial_algoritmos.html
    
   As alterações no código serão atualizadas automaticamente (hot reload).
